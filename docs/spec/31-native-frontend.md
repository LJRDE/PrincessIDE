## 一、已锁定的需求

| 项 | 结论（用户拍板） |
|---|---|
| **形态** | **双前端选配**：Web+JS（Tauri，默认/参考实现）与**原生自绘前端**并存，可切换 |
| **动机** | ① Web 兼容性更好 ② Vulkan 性能更好、可做更精美的动画 ③ **不多一个浏览器内核吃内存** |
| **预算** | **长期并行项目**（明确接受双前端维护成本） |
| **自研边界** | 自研**渲染核心 + 字形图集**；窗口/输入用 `winit`；文本整形用现成库 |
| **第一版视图** | 事件流（虚拟化滚动）、只读代码（语法高亮 + 行号）、hex / 反汇编 |
| **编辑器** | 目标是**可编辑（含 IME）**；但分阶段：**P-E1 先只读**，编辑与 IME 单独一轮（P-E2） |
| **LSP** | **原生第一版不做**（补全/跳转/诊断继续只留在 Web 前端，D17 不重写） |
| **平台** | **X11 + Wayland 都要** |
| **视图模型** | 新增契约域 `princess:view:*`，**引擎算好**，两个前端只负责画（D20 的"并排"落在模型里） |

## 二、三条事实澄清（不改变决定，但决定"收益怎么写"）

1. **Tauri 不打包浏览器内核**（不是 Electron），但它会**加载系统 WebKitGTK**，后者有自己的进程与内存。所以"省掉一个内核"的收益 = **省掉 WebKitGTK 常驻那部分**，**这条成立**（也是本项目 13 个系统包、BUG-004/005 的来源）。
2. **DOM 那条路本来就在 GPU 上**（WebKitGTK 用平台 GL/EGL 合成）。所以"Vulkan 性能更好"必须落到具体场景：**动画流畅度、输入延迟、大视图帧率、渲染控制力**——不是"把渲染搬到 GPU"。
3. **"更精美的动画"是设计自由度收益**（自绘能做 DOM 里别扭的效果），不是性能收益。写卖点时不要混。

## 三、分期与门（每阶段一份任务书，逐阶段独立验收）

### P-E0 视图模型层（前置，必须先做）
- **写**：`10-contracts.md` 新增 `view:` 域（`princess:view:eventlog` / `source` / `hex` / `disassembly`；24 → 28 命令）+ `20-acceptance.md` 验收项；引擎侧视图模型计算（**新 crate**，不进 `princess-core`）；**黄金视图模型夹具（JSON）**；纯函数单测。
- **D20 的硬要求落在模型里**：反汇编每一行必须自带源码行 —— `{addr, bytes, mnemonic, sourceFile, sourceLine}`，**不允许**让两个渲染器各拼一遍。
- **门**：`cargo test` + `node apps/desktop/scripts/check-contract.mjs` = ALIGNED + **同构断言**（同一事件流 → 模型逐字相等）。

### P-E1 原生骨架 + 渲染核心（时限盒，只做只读切片）
- **写**：`apps/native/`（`winit` + 自研 Vulkan 渲染核心：swapchain/帧同步/字形图集/批量绘制 + 现成整形库）+ 事件流（虚拟化滚动）+ hex/反汇编 + 只读代码。
- **不含**：编辑、IME、LSP、插件面板、AI 面板。
- **门**：视图模型同构断言（与 Web 前端比对）＋ **离屏渲染 + 图像哈希**（lavapipe，可无显示器跑）＋ 实测数字（冷启动、按键→上屏延迟、10 万行滚动帧时、LOC）。

### P-E2 代码编辑器（可编辑 + IME）
- **写**：撤销/重做、软换行、选区/多光标、增量高亮、IME 预编辑；X11 与 Wayland 两套输入路径。
- **门**：编辑操作的**模型级无头单测** ＋ **真机勾选清单（只能由用户验收）**。

## 五、风险与退出条件

- **最大风险是"双实现"**：每个新面板都要写两遍。**缓解手段只有一条**：视图模型是共享资产、其单测是共享门；两个前端只换绘制。做不到就应当在第 3 个视图出现时重新评估。
- **IME 只能用户真机验收**（本机无输入法会话）；Wayland 的 `zwp_text_input_v3` 与 X11 是两套，不写在一起测。
- **本机验证能力**：只有 `lvp`（lavapipe 软件光栅），能验**正确性**，**验不了"快多少"**。
- **退出条件（写进 D30）**：P-E1 结束时若 ①冷启动/输入延迟/帧时三项指标不达标，或 ②实现成本明显失控，则**记录数字并砍掉**，不留半成品。
